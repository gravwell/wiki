# J1939

J1939 builds on CAN bus with standardized identifiers and data offsets. It is common in heavy trucking. The j1939 module parses CAN frames and splits the 29-bit identifier into its J1939 fields. With no arguments it extracts every field; name fields to extract only those, optionally with a filter.

| mod | Field | Operators | Example 
|-----|-------|-----------|---------
| j1939 | prio | == != < > <= >= | j1939 prio==1
| j1939 | DP | == != | j1939 DP != 1 
| j1939 | EDP | == != | j1939 EDP == 0 
| j1939 | PDU | == != < > <= >= | j1939 PDU != 0x234 
| j1939 | PF | == != < > <= >= | j1939 PF != 220 
| j1939 | PS | == != < > <= >= | j1939 PS == 0 
| j1939 | SRC | == != < > <= >= | j1939 SRC != 0x23 
| j1939 | data | == != ~ !~ | j1939 data ~ TEST

`prio` is the priority, `DP` and `EDP` are the data page and extended data page bits, `PF` and `PS` are the PDU format and PDU specific bytes, `PDU` is `PF` and `PS` together as a 16-bit value, and `SRC` is the source address. `data` is the frame payload.

The j1939 module also accepts the [canbus](/search/canbus/canbus) fields `ID`, `EID`, `IDE`, and `RTR`.

## Example Search

The following search extracts engine oil temperature from J1939 traffic and charts its variance per source address over time. Trucks whose temperature swings more than others may need maintenance.

```gravwell
tag=trucks j1939 PF==254 PS==238 data | slice uint16le(data[2:4]) as engine_oil_temp | variance engine_oil_temp by SRC over 30s | chart variance by SRC
```
