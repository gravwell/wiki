# Changelog for version 5.10.3

## Released 29 October 2026

## Gravwell

```{attention}
This release contains various security bug fixes. See https://security.gravwell.io for more information.
```

### Additions

* Added Logbot auto execution mode to run tool calls without asking for permission.
* Captured third-party AI health probe response to better support debugging.
* Enabled automatically starting in an unlicensed mode without requiring click through to get started.
* Enabled automatic [rollback to free tier for eligible deployments](free-license) with an expired license.
* Enabled password/TOTP autofill for password managers.

### Bug Fixes

* Fixed an issue where inadvertent concurrent writes in the indexing engine could cause a crash.
* Fixed an issue where license usage requests were rejected.
* Fixed an issue with backups that occurred when a duplicate item already existed.
* Fixed an issue with Logbot stalls on timeouts and failed error detection.
* Fixed various issues in query time constraints.

## Ingester Changes

### Additions

* New [macOS Unified Log Ingester](/ingesters/macos_unified_log).

### Bug Fixes

* Fixed an issue with an ingester standup hanging on connection stalls.
* Made an ingester throw an error when starting a cache if the tag map is missing but data exists.
