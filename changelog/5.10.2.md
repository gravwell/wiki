# Changelog for version 5.10.2

## Released 30 September 2026

## Gravwell

### Additions

* Added the ability to insert newlines for multi-line Logbot chat messages. `Shift`+`Enter` now sends.
* Added logging to external MCP tool calls.

### Bug Fixes

* Fixed an issue with displaying inline code markdown in Playbooks.
* Fixed an issue with AI tool call encoding for some assets.
* Fixed an issue where Logbot query reported an empty query error and the copy button would not work.
* Fixed an issue where a stalled or cancelled Logbot would prevent Logbot from responding to any additional queries in the same session.


## Ingester Changes

### Bug Fixes

* Fixed an issue with Jamf plugin entries being too long by separating each section into its own tag.
* Fixed an issue with starting a hosted ingester when the tag map is empty.
* Fixed an issue with a context cancellation loop in the Kinesis ingester.
* Fixed an issue with the Azure Event Hubs ingester stalling.
